# Задание 2. Разработка и заполнение проверочного листа для бизнес-систем.

## Разделы включенные в проверочный лист, исходя из проблем и приоритетов компании.
Для анализа проблемы "Нарушен контроль данных" - необходим раздел "Безопасность данных".
Для анализа "проблемы с API партнёров" - необходим раздел "Управление доступом".
Для потребностей бизнеса и реализации целей бизнеса к этим разделам необходимо добавит раздел "Управление инцидентами".
